plan-12: implementation plan
============================
Written 2026-10-23 (orchestrator), after the decisions (02-design
"Decisions"); the contract is 04-contract.txt. Paths as there. Nothing
committed by the streams; the user commits.

Rules for every stream
----------------------
- Read first: N/.github/skills/coding-style/SKILL.md; this directory's
  00, 01, 02 (Decisions, N), 03, 04; then the sources of your stream.
  E2E also reads N/.github/skills/run-e2e-tests/SKILL.md.
- Edit only the files your stream owns; anything else is a Request in
  your status file. Never write under ~/github.com/askervin/.
- Plain ASCII; comments say what, not how or who calls; current state
  only; match the surrounding code.
- No host installs. One run_tests.sh at a time; the VMs belong to E2E,
  root@cwf to HW.
- Status file 05-status-<S>.txt: changes per file, deviations from
  04-contract with reasons, verification commands and their decisive
  output, open points, Requests; end with "<S> done".
