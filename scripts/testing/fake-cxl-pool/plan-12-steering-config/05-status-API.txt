Functions and methods
  func Resolve(claim *resourceapi.ResourceClaim, driver, request string) (*Resolved, error)
      the MemoryConfig of one allocation result (contract 3): entries of the
      driver that target the request, class entries first, each decoded
      strictly alone, source table, merge patch, strict decode of the
      merge, validation of container and pool values; origins of the set
      container fields ("claim NS/NAME request R", "class NAME").
  func CheckEntries(claim *resourceapi.ResourceClaim, driver string) error
      checks every entry of the driver alone (kind, apiVersion, fields,
      source table) whatever requests it targets; replaces
      checkConfigKinds (before any device is touched).
  func (r *Resolved) Settings() ResultSettings
      the container section and its origins, the input of Combine.
  func (c *MemoryConfig) DeviceSection() Device
      the device section, zero Device when absent (nil-safe).
  func (c *MemoryConfig) Compact() string
      sections as compact JSON without apiVersion, kind and empty
      sections ("{}" for none): the %s of the section 11 Prepare logs.
  func (d Device) MemdevMode(shared bool) (string, error)
      local memdev slice / shared local memdev; replaces modeFor.
  func (d Device) NUMAOnly(what string) error
      region and dram (what: device.DeviceTypeRegion, DeviceTypeDRAM);
      replaces numaOnly.
  func (d Device) CheckLease() error
      the lease device: no device field.
  func (d Device) PoolMode(f PoolFacts) (string, error)
      pool devices; replaces poolModeFor (PoolFacts{d.Persistent,
      d.Shared, d.Exclusive} of poolDevice).
  func PoolOpaque(r *Resolved, key string, out any) (found bool, err error)
      strict decode of pool.opaque.<key>; other keys ignored.
  func Combine(results []ResultSettings, defaults Container) (*Effective, error)
      contract 5: agreement per field, defaults overlay, built-in
      defaults, validation of the effective steering with origins.
  func (e *Effective) Steers() bool
      effective policy is not none.
  func (e *Effective) PolicyText() string
      "none (default)", "auto from claim ns/a request r", "first-dram
      (node default)": the steering %s of the section 11 log.
  func (s *Steering) CgmPolicy(mem cgmpolmgr.MemoryTypes) (cgmpolmgr.Policy, bool)
      the cgmpolmgr policy; false for nil, "" or none, or no DRAM and no
      CXL nodes; auto by nodes as today's defaultPolicy (no CXL nodes:
      first-dram, no DRAM nodes: first-cxl, both: start-interleaved);
      minStep, maxStep, waypoints copied.
  func ParseDefaults(data []byte) (*Defaults, error)
      YAML or JSON, strict (case sensitive), validated.
  func (d *Defaults) Validate() error
      fencing (mempolicy refused) and steering as an effective steering.
  func (d *Defaults) ContainerSettings() Container
      the defaults.container to pass to Combine (zero when absent).

Deviations from 04-contract, with reasons
-----------------------------------------
D1. Combine returns (*Effective, error), not (Container, error):
    Effective has the container settings and the origin of every field,
    for the section 11 log ("auto from claim ns/a request r", "none
    (default)", PolicyText) and the effective-validation errors. The
    conflict error has no "container ns/pod/ctr: " prefix: Combine does
    not know the container; the caller adds it (section 5 text then
    matches exactly).
D2. Resolve does not validate the device section. The rules and their
    order depend on the driver and the device type (local: "(numa or
    dax)", pool: "(numa, dax, block or fs)" and access/path before the
    mode facts), so all device checks are in the Device helpers, which
    the drivers call per result as they call modeFor/poolModeFor today.
    The pool controller is not affected (it reads pool only).
D3. "policy waypoints requires waypoints" is checked on the effective
    steering only (Combine, Defaults): waypoints may come from another
    result or from defaults with the same policy. Per result: invalid
    values, parameters with an explicit none, waypoints with an
    explicit other policy, minStep > maxStep when both are set.
D4. Defaults overlay: the steering parameters of the defaults
    (waypoints, minStep, maxStep) are taken only when the results set no
    policy or the default's policy. Steering is a discriminated union;
    without this rule a node default {policy: first-dram, maxStep: 1Gi}
    would make every claim with {policy: none} fail ("maxStep needs a
    policy other than none"). Review point.
D5. Strict decoding is case sensitive and refuses duplicate fields
    (sigs.k8s.io/json, as Kubernetes): encoding/json matches "Mode" to
    mode, and the merge patch would keep "Mode" and "mode" side by side.
    Its unknown-field error names the dotted path: `json: unknown field
    "x"` at the top (the contract example exactly), `json: unknown field
    "device.x"` nested.
D6. Source table: a null value does not count as setting a field, so
    {container: {fencing: null}} or pool: null is accepted in any entry
    (null removes, and in a claim it can only remove a value back to the
    default). Table: sourceRules in resolve.go, one line per field with
    allowed(source, driver); an admin-only field later is
    {path, allowed: source == FromClass, reason: "set by a DeviceClass only"}.
D7. pool is refused for driver cxl.nri.io (device.DriverName), allowed
    for any other driver: the pool driver name is configurable
    (--pool-driver-name). The text names cxl-pool.nri.io as in the
    contract.
D8. Added CheckEntries (contract 8 has no replacement of
    checkConfigKinds): the Prepare can refuse an unknown kind or field
    in any entry of the driver before touching devices, as today.
D9. The entry index of "SRC config I" is the position among the
    allocation's entries of that source (all drivers counted), from 0.
D10. Policy names, memory types and field names are case sensitive
    (cgmpolmgr matches names without case); a memory type twice in one
    waypoint is refused (cgmpolmgr took the last).
D11. Lease device text is new (the contract has the rule but no text).
D12. ParseDefaults added (strict YAML/JSON) next to Validate.
D13. Class origins come from the claim spec (device class of the
    request or subrequest); when the request is not in the spec:
    "class of request R".
