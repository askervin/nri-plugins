New helpers: usage
------------------
  dra-memory-config SECTIONS
      "{apiVersion: cxl.nri.io/v1alpha1, kind: MemoryConfig, SECTIONS}",
      for inline YAML (parameters: $(dra-memory-config "device: {mode: dax}")).
  dra-claim-yaml claim|template NAME CLASS SIZE [MODE [read-only]] [device=F] [container=F] [pool=F]
      dra-claim-yaml claim s cxl-local 128Mi "container=steering: {policy: auto}"
  dra-claim-pod VMDIR NAME CLASS SIZE [MODE [read-only]] [SECTION=F...]
  dra-shared-claim-yaml NAME SERIAL [SHARES [PARAMETERS [CLASS]]]
      dra-shared-claim-yaml p 0xc1ee0002 "" "pool: {opaque: {fake-cxl-pool: {numaNode: 1}}}" cxl-pool
  dra-pod-yaml NAME NODE [CNAME=claim:CLAIM|CNAME=template:T...] [-- CTR[=REF[,REF...]]...]
      REF is CNAME or CNAME/REQUEST; default one container main with all
      claims; every container runs DRA_RUNNER, /tools mounted.
      dra-pod-yaml split node mem=claim:split -- c-numa=mem/numa c-dax=mem/dax
  dra-run VMDIR POD[/CTR] SCRIPT [TIMEOUT]
      SCRIPT as a child of the main process; one kubectl exec writes it
      and waits in the container; COMMAND_OUTPUT, exit status (124 on
      timeout). Tested locally with the runner: output, rc, timeout.
  dra-container-mempolicy VMDIR POD CTR
      the policy of the container's init process from /proc/PID/numa_maps
      ("default", "prefer:2", "interleave:0-2").
  dra-memory-wait VMDIR POD CTR steered|fenced|none [STEERING]
      waits for "NRI CreateContainer: ctr=NS/POD/CTR: memory MGMT
      (steering STEERING" in the driver log; steered: waits until
      memory.high != max and policy != default; fenced/none: memory.high
      max and policy default. Sets DRA_MEM_HIGH, DRA_MEMPOLICY.
  dra-nodes-subset LIST1 LIST2
  dra-touch-log-pages TEXT NODES
  dra-claim-condition-watch VMDIR CLAIM TYPE REASON [TIMEOUT]
      kubectl get -w -o json parsed in python in the VM, kubectl killed
      when found or at the timeout. Tested locally with a fake kubectl
      (found in 1 s; timeout path rc 1).
