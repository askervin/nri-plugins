Result
------
The claim configuration of the CXL DRA driver is one kind, MemoryConfig
(apiVersion cxl.nri.io/v1alpha1), for the node driver (cxl.nri.io), the
pool driver (cxl-pool.nri.io) and pool controllers, with three sections
by owner: pool (the pool controller; pool.opaque.<controller key>),
device (the kubelet plugin), container (the NRI plugin). Steering is
opt-in (default policy none; one line opts in). Class and claim entries
merge field by field; node defaults are the driver configuration's
defaults.container. Containers are attributed per allocation result
(CXL_CLAIM_<uid>_<n>). Pool numa memory is steered like local memory on
opt-in. All e2e tests pass; the hw tests have no new failure.
