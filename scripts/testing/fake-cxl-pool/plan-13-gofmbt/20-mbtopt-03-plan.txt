Then (orchestrator)
-------------------
INTEGRATE: apply MODEL's and DEBUG's changes to the main checkout's
  model (resolve overlaps), fast-forward 5jo-mbt-cxl to GOFMBT's
  branch if accepted; run the model test suite, the seeded
  experiments against the baseline numbers (D6), gofmbt's tests,
  test06-fuzz generate.go output comparison. Write 05-results.
RUNS (Opus, medium): long simulated runs of the integrated model
  (several seeds, 2000-4000 steps, depth 3 and depth 4, default mix;
  --plan-time 0 for reproducibility), then the cluster: test90 with
  MBT_DURATION=120m (L10) as 06-runs.txt L8/L9 were run, after
  checking that nothing else uses the three VMs. Record in
  20-mbtopt-06-runs.txt.
DEBUG-N (Opus, xhigh): every disagreement or failure of RUNS, one
  agent each, same deliverables as DEBUG.

Measurement protocol (every stream reports these, same host)
------------------------------------------------------------
  B=/tmp/mbtopt/<work>/mbt-cxl built with the stream's go.work
  $B experiment --exp plantime --max-depth 4 --seed 1 --steps 30
  $B experiment --exp growth --mixes C1x3,C2x2,C3 --depth 3 --seed 1 --steps 300
  $B experiment --exp growth --mixes C1x3,C2x2,C3 --depth 3 --seed 2 --steps 300
  (300, not 400: the baseline hits M8 at step 330 with seed 1)
  /usr/bin/time -v for the RSS; --cpuprofile for the profile.
Baseline (01-findings F3): depth 3 541 ms mean / 2.36 s max, depth 4
5.8 s / 12.5 s; growth seed 1 @100 C1=56 C2=120 C3=144 C4=78, @200
C1=122 C2=191 C3=221 C4=143 (these numbers must not change for a
semantics-preserving optimization: the run is seeded and no deadline
is hit).
Baseline RSS 50-60 MB.

---------------

  the baseline coverage numbers; the completeness test of the key
  passes; the per-plan memory is bounded and reported.
- G: gofmt, go vet, go test ./... and go test -race ./... pass; the
  player example output is byte-identical; test06-fuzz generate.go
  output is byte-identical to the 5jo-mbt-cxl build.
- Both: the same experiment numbers with G's branch as with
  5jo-mbt-cxl (D1 changes no result).
