Contract section 1 (pkg/cxl/config: types.go, device.go)
--------------------------------------------------------
- Device gains FsType string `json:"fsType,omitempty"` (last field, so
  Compact output of existing configs is unchanged).
- Device.ReadOnly is *bool `json:"readOnly,omitempty"`. Accessor:
      func (d Device) IsReadOnly() bool
  readOnly when set; else true for mode fs (d.Mode == "fs") and false for
  every other mode. Drivers never dereference ReadOnly.
  To set it in Go: ptr.To(true) (k8s.io/utils/ptr); in package main of the
  driver the existing generic ptr(v) helper (node_state.go) shadows that
  import name, so broker.go uses ptr(true).
- Merge and decoding unchanged: a merge with "readOnly": null removes the
  field (IsReadOnly falls back to the mode's default); "readOnly": false is
  kept as a set value (Compact shows it); strict decoding as before.
- Facts type (replaces PoolFacts):
      type DeviceFacts struct {
          Persistent, Shared, Exclusive, SingleHost, Coherent, Local bool
      }
  meanings as in contract section 1 (field comments say them).
- Mode functions:
      func (d Device) PoolMode(f DeviceFacts) (string, error)
          pool devices (volatile and persistent); Local false.
      func (d Device) PersistentMode(f DeviceFacts) (string, error)
          a persistent device: PoolMode with f.Persistent = true; the local
          driver calls it for local persistent memdevs with Local true.
  One rule set (one implementation): section-alone checks, then the
  facts checks, then F1-F3 (only when !IsReadOnly()).
- Unchanged signatures: MemdevMode(shared bool), NUMAOnly(what),
  CheckLease(). MemdevMode and NUMAOnly also refuse fsType with C1.
  CheckLease refuses any set field, fsType included; readOnly: false is
  accepted as today (it was indistinguishable from absent before).
- Controller helper:
      func ExclusiveHost(resolved MemoryConfig, coherent bool) bool
  mode fs, !IsReadOnly(), and not (FsTypeCluster(fsType) && coherent).
  Call it with Resolved.Config.

Order of PoolMode / PersistentMode checks (texts in section "Texts"):
  invalid mode; access needs mode fs; path needs mode fs; C1 fsType needs
  mode fs; C2 invalid fsType; invalid access; invalid path; readOnly with
  mode numa; then facts: mode X needs a persistent device; a persistent
  device needs mode block or fs; then F1 (local text when f.Local), F2,
  F3; then the volatile rules (shared dax only; readOnly needs dax...).

Contract section 2 (pkg/cxl/config/fstypes.go)
----------------------------------------------
  const FsTypeErofs, FsTypeSquashfs, FsTypeExt4, FsTypeXfs, FsTypeBtrfs,
        FsTypeGfs2                        ("erofs", ... "gfs2")
  const FsClassReadOnly = "read-only", FsClassSingleHost = "single-host",
        FsClassCluster = "cluster"
  var   KnownFsTypes = []string{erofs, squashfs, ext4, xfs, btrfs, gfs2}
  func  ValidFsType(name string) bool     ^[a-z0-9][a-z0-9_-]{0,31}$
                                          (same as api.ValidFsType)
  func  KnownFsType(name string) bool
  func  FsTypeClass(name string) string   unknown types: single-host
  func  FsTypeReadOnly(name string) bool  erofs, squashfs
  func  FsTypeCluster(name string) bool   gfs2 (by type; the instance with
                                          lock_nolock is the probe's: P8)
  func  FsTypeDAX(name string) bool       erofs, ext4, xfs
  func  FsMountData(name, access string, readOnly bool) []string
        items "key" or "key=value" in order: dax=always (access direct) or
        dax=never (any other access) for DAX types; then nouuid for
        read-only xfs, spectator for read-only gfs2. Nothing else ever
        (no lockproto, locktable, noload, norecovery, user options).
        For fsconfig: split at "=" (FSCONFIG_SET_STRING) or flag
        (FSCONFIG_SET_FLAG); for mount(2) data: strings.Join(items, ",").
        Read-only types are given readOnly true by the caller (they are
        never mounted read-write; P6 refuses that before).

Contract section 6 (pkg/cxl/api, cmd/cxl-request)
-------------------------------------------------
- api.Request: ReadWrite bool `json:"readWrite,omitempty"` (after
  ReadOnly), FsType string `json:"fsType,omitempty"` (after Access).
- api.Response: FsType string `json:"fsType,omitempty"` (after Access).
- api.Memory: FsType string. api.Env: CXL_<KEY>_FSTYPE for mode fs when
  Memory.FsType != "" (the drivers always set it for fs; no empty variable
  otherwise); mode block never has FSTYPE.
- api.ValidFsType(name string) bool (the C2 regexp; config.ValidFsType
  calls it: pkg/cxl/api has no dependency on config).
- Validate order: V1 source, V2 mode, V3 access (validateValues), V4
  shared numa, V5 access needs mode fs, V6 name needs mode fs, V7 invalid
  name, V8a, V8b, V8c, V8d, "mode block with shared needs readOnly"
  (kept, unnumbered in the contract), V9, "size or serial is required",
  "invalid serial" (V11, V12). Removed: "mode fs needs readOnly",
  "mode fs needs source pool", "mode block needs source pool".
- cxl-request request: --read-write (flag, also --read-write=BOOL) and
  --fs-type TYPE (value); options order: --source --mode --shared
  --read-only --read-write --access --fs-type --name --size --serial
  --wait --request-id --exec; synopsis line 2 "[--read-write] [--access
  direct|cached] [--fs-type TYPE] [--name NAME]"; help as the contract
  with the file's column alignment ("--read-write fs: mount the filesystem
  read-write (default read-only)", "--fs-type   fs: the expected
  filesystem type (default: detected)"); --mode, --read-only and --access
  help say: fs/block of "a persistent device" (not "pool device"), fs is
  read-only without --read-write, access default direct when the
  filesystem has DAX, cached otherwise. Validation errors exit 2 before
  connecting (tested).
