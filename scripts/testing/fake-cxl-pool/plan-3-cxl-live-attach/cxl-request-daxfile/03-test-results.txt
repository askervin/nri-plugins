4. Life cycle requirements, as tested
-------------------------------------
| order | result |
|---|---|
| request, use by path, release, repeat (3x) | no leftovers after each release: file, mount, private node, companion, claim, region, attachment |
| release while a program maps the file | release not blocked; program gets SIGBUS; no leftovers |
| requester pod deleted with a file lease in use | file gone with the container; node removed; lease released with the token claim; no leftovers |
| companion unprepared behind the broker (OnReleasing) | unit test: file removed before the device; an unmount error fails the unprepare and keeps the device |
| plugin restart with files | unit test: files kept in leases.json, removed at release |
| container instance ends, lease kept for a restart | unit test: file dropped, node removed, lease stays |
Not tested on the VM: a plugin restart with a mounted file, a container
restart with a file (the file is gone, the lease stays; request it again
with `cxl-request file LEASE PATH`), CRI-O, SELinux enforcing (disabled in
VM2), a user namespace pod.
