  --lease-cli-source      LEASE_CLI_SOURCE      ""

  --lease-companion-image LEASE_COMPANION_IMAGE registry.k8s.io/pause:3.10
  -v and the other klog flags, -version.
Semantics: the command line wins; a flag that is not on the command line
takes the value of its environment variable when that is set (applied with
flag.Set, so invalid values fail: "invalid LEASE_WAIT=..."). Usage texts
name the variables. Positional arguments are an error. Bool flags need the
"=" form: --leases=false (Go flag; the chart already does this).
--lease-cli-source PATH: in run(), after the plugin dir and CDI root and
before newDriver (so before any CDI spec): mkdir -p dir(--lease-cli)
(0755), copy to a temporary file in that directory, chmod 0755,
selinuxLabel (the label of the lease socket directories, best effort),
rename over --lease-cli. Any failure stops the driver (exit 1). Done
whenever --lease-cli-source is set, also with --leases=false (contract
text). --lease-cli-source with an empty --lease-cli is a usage error.
