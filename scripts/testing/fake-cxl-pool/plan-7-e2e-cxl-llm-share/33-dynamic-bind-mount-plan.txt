The VMs
-------

ssh -F <dir>/.ssh-config vagrant@node) are running, one cluster of three
nodes (VM2 control plane), kernel 7.3.0-rc4 with CONFIG_EROFS_FS, no CXL

needed. Only T uses them, and only in its phase 2. If a run leaves the
cluster broken, T repairs with the tools of the tests (pool-vm-reset,
dra-uninstall) before the next run and notes it.

Order
-----
1. D and T phase 1 start together.
2. D done -> the orchestrator tells T the image id -> T phase 2.
3. T's driver findings -> orchestrator -> D fixes -> new image -> T reruns.
4. Reviews (35-dynamic-bind-mount-review-D.txt, -T.txt) by the
   orchestrator and a reviewer agent; fixes; final runs.
