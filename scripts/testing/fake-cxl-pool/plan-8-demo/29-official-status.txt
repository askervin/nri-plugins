Notes
-----
- With a writer on a node there is one superblock: a read-only claim of
  the same node gets a read-only bind of it, so the driver logs one
  read-write mount and no second read-only one (plan-14 design).
- The pool demos take the newest driver image of build/images; the demo
  image (localhost/cxl-demo-tools, now with e2fsprogs, xfsprogs,
  btrfs-progs) is built on the host by setup when missing.

  on the host to attach a loop device (opt-in, not run by default).
